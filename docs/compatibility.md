# 书源能力矩阵（首批实现）

这张表描述规则引擎已实现的语义子集，不代表真实书源可用率。来自 `source.jwyihao.top` 的 11 条去重书源、5 个关键词的在线搜索实测与分源失败原因见[在线实测](live-source-tests.md)。

| 能力 | 状态 | 边界 |
| --- | --- | --- |
| 单个/数组 JSON、`sourceUrls` 合集 | 已实现 | 合集递归深度最多 3；覆盖同 ID 书源 |
| 本地文件、剪贴板、URL 导入 | 已实现 | URL 由用户主动输入；无自动订阅更新 |
| 单源及多源搜索 | 已实现 | 每源第 1 页；核心接口接受页码，UI 暂无翻页按钮；无匹配条目返回空结果 |
| 详情、目录、正文 | 已实现基础链路 | 目录与正文下一页最多 50 页；不执行预更新脚本和付费动作 |
| CSS、XPath、JSONPath、正则 | 基础子集 | 支持单段选取与 `@text/@html/@href` 等单动作；列表元素上可直接用 `text`、`href`、`src`；不保证 Legado 复合表达式等价 |
| 规则内 JS、`mainJs` | 基础子集 | Rhino 执行；`mainJs` 支持 search/getBookInfo/getChapters/getContent，`getBookInfo` 可省略；详情字段会合并到搜索结果，章节相对地址按目录地址解析；仅暴露 `java.ajax` |
| 手动登录、Cookie、WebView | 已实现基础链路 | HTTP 跳转链共享 Android Cookie；WebView 请求仅 GET，登录验证、WebJs、验证码处理未实现 |
| TXT/EPUB 导出 | 已实现 | 仅文本章节；EPUB 是最小 EPUB 2，暂不含封面、插图或复杂排版 |
| 漫画/音频/视频/文件 | 基础资源获取与按需下载 | 漫画从正文 HTML 的 `img[src]` 提取并可打包 ZIP；音视频取第一个解析链接；文件源展示下载链接并可选一个下载。尚不处理媒体流清单、分段流或解密 |
| 断点继续与取消 | 基础实现 | 成功章节逐章缓存；失败章节在下次导出时重抓；任务状态未跨进程持久化 |

导入预检对 `mainJs`、发现、段评、登录检测、封面解密、批量正文、付费动作、WebJs 及超出 `java.ajax` 的脚本宿主方法给出提示。预检只做能力提示，不证明书源实际可运行。特别是复杂书源依赖的 Java 宿主 API、共享变量、字体解密、登录态、请求时序和网页脚本，仍可能在运行阶段失败。运行错误会包含阶段和字段；后续应将该结构直接展示在 UI 的逐阶段诊断页。

不兼容样例不应默默改写为近似结果。扩展顺序建议：先收集失败样本和预期输出，补该规则语义与回归测试，再更新此矩阵。真实站点的访问状态、账号状态和规则语义要分别记录。

目前还未复刻原版的 `bookUrlPattern` 直达详情回退、书源变量/书籍变量、目录分卷与 VIP 标记、跨源换源、批量正文和规则优先级。遇到依赖这些行为的书源，需要用阶段错误和预检结果识别后再扩展。
