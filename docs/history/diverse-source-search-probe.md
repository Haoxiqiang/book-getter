## 确认的规则差异

官方 [AnalyzeByJSoup.kt](../../../legado/app/src/main/java/io/legado/app/model/analyzeRule/AnalyzeByJSoup.kt) 的 `ElementsSingle` 把 `tag.a.0` 解释为第一个匹配节点、`tag.span.-1` 为最后一个、`tag.tr!0` 为排除第一个；这与普通 CSS `.0` 完全不同。`RuleEvaluator.select` 现支持这些基础后缀，合成 HTML 回归同时验证索引、排除和绝对 URL。飞卢同一公开搜索从 0 变为 30 条，说明真实规则链路可用；未验证详情/目录/正文，也未据此宣称该源全部兼容。

未解决的广度问题：`[]` 多索引/区间、复杂组合索引仍需按官方实现补测；非 200 的 HTTP 202 以及 200 跳转/停放页需要更明确的响应分类；Android WebView 源要在设备上验证。后续优先选择**可正常返回且使用不同规则特性**的站点做搜索、详情、目录小步验证，不以同站多本下载替代跨站兼容覆盖。
