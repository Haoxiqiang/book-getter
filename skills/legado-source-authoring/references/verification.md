# 书源验证与交付

针对用户要求的阶段验证，而非机械跑完整小说流程。普通书源依次观察所需的搜索/发现、详情、目录、正文；RSS 观察分类或搜索、XML/自定义列表、翻页和文章阅读。每步记录请求方法、脱敏 URL/选项、状态码、编码、最终基址、规则与关键字段。真实页面的选择器需在当前 HTML/JSON 上验证；站点变更、403、登录页或反爬不能当作零结果或选择器失败。

至少区分三类结论：已在官方 App 或可重复实测中通过、只在静态/离线夹具中验证、因站点或环境条件仍待验证。Python 模拟器或本项目 Java 解析器的结果不能独自证明官方 App 可用。若用户只提供部分页面，可交付与该证据相符的草案并列出尚需的页面/步骤；不要编造字段或宣称全链路可用。

交付 JSON 时核对实体类型、字段名、转义、URL 选项、单对象或用户指定入口所需数组包装。附简短说明：使用的页面与时间、已验证的阶段、需要登录/WebView/付费等前提、未验证字段。不要复制未经授权的第三方完整书源或作品正文；测试夹具和日志应脱敏，付费、发布、删除等动作只在已有授权范围内执行。
